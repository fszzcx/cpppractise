# 分支结构热身练习（cin/cout 版）

> 目标：练熟 cin/cout + if-else / switch，为原版三道作业（区间判断、三位排序、计算器菜单）做铺垫。  
> 全部用 `cin`/`cout` 完成，头文件用 `<iostream>`，需要小数格式时加 `<iomanip>`。

---

## 题1（热身）：整数体检报告

从键盘读入**一个整数** n，输出两行体检结果：

- 第一行：n 是偶数输出 `Even`，奇数输出 `Odd`
- 第二行：n 是正数输出 `Positive`，负数输出 `Negative`，恰好是 0 输出 `Zero`

**练什么**：`cin >> int`、`%` 取余、if-else / else if 链

**提示**：

- 奇偶判断用 `n % 2` 想清楚负数时它的值（比如 `-3 % 2` 是多少？用程序试一次就记住了）。
- 三分支用 `if ... else if ... else`，不要写成三个独立的 if。

**自测用例**：

| 输入 | 第一行  | 第二行      |
| -- | ---- | -------- |
| 7  | Odd  | Positive |
| -4 | Even | Negative |
| 0  | Even | Zero     |

## 题2（进阶）：三人比身高

从键盘**一次性**读入三个小数 a、b、c（三个人的身高），输出其中**最大的**那个，保留 1 位小数。

**练什么**：`cin >> a >> b >> c` 连续读入、浮点输出 `fixed << setprecision(1)`、嵌套 if

**提示**：

- 不需要排序，只要"找出最大"——先假设一个是最大，再逐个比较替换，或者两两比较，两种思路都可以。
- 输出样例：输入 `1.72 1.85 1.63`，输出 `1.9`（保留 1 位后 1.85 → 1.9）。

**自测用例**：

| 输入             | 输出   |
| -------------- | ---- |
| 1.72 1.85 1.63 | 1.9  |
| 3.0 2.9 2.9    | 3.0  |
| -1 -2 -3       | -1.0 |

## 题3（收尾）：自动售货机

饮料机菜单如下：

```
1. Cola    3.0 元
2. Coffee  4.5 元
3. Water   2.0 元
```

先读入一个整数（选择的编号），再读入一个小数（投币金额）：

- 编号是 1/2/3 且钱够 → 输出 `Change: x.x`（找零，保留 1 位小数）
- 编号是 1/2/3 但钱不够 → 输出 `Not enough money`
- 编号不是 1/2/3 → 输出 `Invalid`

**练什么**：if-else if-else 链 + 嵌套判断、加减法 + `setprecision`、"先查价格再统一处理"的结构化思路

**提示**：

- 先判断编号合法性，再用 `if (num == 1) price = 3.0; else if (...) ...` 查出价格——这种"查表"写法是 if 链的经典用法。
- 价格查出来后，钱够不够只需要**一处** if 判断，不用给每种商品各写一遍。
- 金额比较用 `money < price` 就行，这题不需要浮点判等。

**自测用例**：

| 输入     | 输出               |
| ------ | ---------------- |
| 1 5.0  | Change: 2.0      |
| 2 3.0  | Not enough money |
| 3 2.0  | Change: 0.0      |
| 4 10.0 | Invalid          |

**进阶挑战（学完 switch 后再做）**：这题的"查价格"部分正好适合用 `switch-case` 重写——`case 1/2/3` 各赋一个价格，`default` 处理非法编号。到时候回来重写一次，对比两种写法哪个更清晰，switch 就算真的学会了。
