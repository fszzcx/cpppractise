# 第一部分：动态内存

## 一、先认识四个新面孔：`*`、`void`、`size_t`、`NULL`

### 1. `*` 在这里是"指针"标记

你已经学过指针了，这里复习一下它在代码里的样子：

```c
int *p;          // 声明一个指针 p，它存的不是数字，而是"某个 int 变量的地址"
p = &x;          // & 是"取地址"：把变量 x 的地址赋给 p
*p = 5;          // * 出现在语句里表示"顺着地址找过去"，即往 x 里写 5
```

记住三句话：

- **声明时**的 `int *p`：告诉编译器"p 是个指针，指向 int"。
- **使用时**的 `*p`：表示"p 指向的那个变量本身"。
- **`&x`**：取 x 的地址。`&` 和 `*` 是一对相反操作。

`malloc` 返回的就是一个"地址"，所以要用指针变量接住它。

### 2. `void` —— "空 / 什么类型都不是"

`void` 读作"沃伊德"，意思是**没有类型**。你已经在 `int main(void)` 里见过它了，那里表示"main 不接收参数"。   

在动态内存里它以 `void *` 的形式出现：

```c
void *malloc(size_t size);   // malloc 的返回类型是 void *
```

`void *` 的意思是：**一个"不指定类型"的通用地址**。因为 malloc 不知道你拿这块内存去存 int 还是存结构体，它只负责给你一块地，具体当什么用由你说了算。C 允许把 `void *` 直接赋给任何具体类型的指针：

```c
int *p = malloc(n * sizeof(int));        // void* 自动转成 int*，不用强制转换
Student *stu = calloc(n, sizeof(Student));
```

### 3. `size_t` —— "表示大小的无符号整数类型"

`size_t` 不是新关键字，它是一个**已经定义好的类型别名**（在标准库里用 `typedef` 做出来的），专门用来表示"内存大小、元素个数"这类东西。你可以暂时把它当成"非负整数"来读：

```c
void *malloc(size_t size);   // 参数 size 是个非负整数：要多少字节
```

写代码时你传普通 `int` 进去也能用，不用刻意写 `size_t`。

### 4. `NULL` —— "空指针，什么都不指"

`NULL` 是标准库定义的常量，值就是 0，表示**这个指针不指向任何有效内存**。两个用途：

```c
int *p = NULL;               // 声明指针时先给它个"空"，避免它存着随机垃圾地址

if (p == NULL) { ... }       // 判断"这块内存到底拿到手没有"
```

`malloc` 借内存失败时（比如内存不够）不会报错退出，而是**返回 NULL**。所以拿到返回值后第一件事就是判 NULL：

```c
if (p == NULL) {
    fprintf(stderr, "内存分配失败\n");   // 打印错误信息
    return 1;                            // 非零返回值表示程序异常结束
}
```

顺便解释这两个你可能没细看的：

- **`fprintf(stderr, ...)`**：见第二部分第 3 节，`fprintf` 就是"往指定地方打印"，`stderr` 是"标准错误输出"（默认也是屏幕）。嫌复杂就先写成 `printf` 也行，只是习惯上错误信息走 stderr。
- **`return 1;`**：main 返回 0 表示"程序正常结束"，返回非 0（习惯上 1）表示"出问题了"。给操作系统看的，不影响你。

## 二、四个函数逐个拆解

### 1. `malloc` —— memory allocate，按字节借内存

```c
int *p = malloc(n * sizeof(int));
```

从左往右读这句话：

- `malloc(...)`：向系统申请一块内存，返回这块内存**第一个字节的地址**。
- `n * sizeof(int)`：要多少**字节**。`sizeof(int)` 在你的机器上通常是 4（一个 int 占 4 字节），所以要存 n 个 int 就得要 `n × 4` 字节。

⚠️ **最容易犯的错**：写 `malloc(n)`。你只借了 n 个字节，只够放 n/4 个 int！记住公式：**malloc 里永远写 `个数 * sizeof(类型)`**。

借来的内存里**原来的内容是随机的垃圾值**（不像数组初始化），用之前要自己赋值。

### 2. `calloc` —— 和 malloc 类似，但帮你清零

```c
int *p = calloc(n, sizeof(int));
```

注意和 malloc 的区别：**calloc 有两个参数**——个数在前、单个大小在后，参数顺序反了很容易搞混（这也是个经典坑）。它的额外好处是把借来的内存**全部清成 0**。

对比记忆：

```c
malloc(10 * sizeof(int))   // 10 个 int 大小的垃圾值内存
calloc(10, sizeof(int))    // 10 个 int 大小的全 0 内存
```

### 3. `realloc` —— re-allocate，改变之前借的内存大小

```c
int *tmp = realloc(p, 20 * sizeof(int));   // 把 p 指向的空间从 10 个 int 扩到 20 个
```

三个新知识：

- **为什么要临时变量 tmp 接？** realloc 可能原地扩容（返回原地址 p），也可能原地放不下、另找一块更大的地方并把旧数据**复制过去**（返回一个新地址）。所以**必须用返回值**，不能假设地址不变。
- **为什么不直接 `p = realloc(p, ...)`？** 如果扩容失败，realloc 返回 NULL，这一赋值你就把原来 p 里存的好好的地址**覆盖丢了**——旧内存既用不了也还不掉，永久泄漏。先用 tmp 接住，确认不是 NULL 再赋给 p，才安全。
- 原有的数据在扩容后**依然保留**，不用你自己搬。

### 4. `free` —— 把借的还回去

```c
free(p);       // 把 p 指向的那块堆内存还给系统
p = NULL;      // 还完之后 p 里的地址已经"作废"了，置成 NULL 防止误用
```

两个要点：

- free 的参数就是**当初 malloc/calloc/realloc 返回的那个指针**，一个字都不能偏（不能 free(p+1)）。
- free 之后 p 里存的还是那个旧地址，但那块地已经不归你了。如果接着用 `*p`，就是**悬空指针**——程序可能看着正常，也可能崩溃，是最阴险的 bug。所以 free 完立刻 `p = NULL;`，之后万一误用 `*p`，程序会立刻崩溃报错，反而好查。

## 三、把注释标到每一行——完整例子

```c
#include <stdio.h>    // printf、scanf 在这里
#include <stdlib.h>   // malloc、calloc、realloc、free、NULL 都在这里！

int main(void) {
    int n = 5;

    // 声明一个"指向 int 的指针"p，用 malloc 返回的地址初始化它
    int *p = malloc(n * sizeof(int));   // 借"5 个 int"那么大的内存

    if (p == NULL) {                    // malloc 失败返回 NULL，必须检查
        fprintf(stderr, "内存分配失败\n");
        return 1;
    }

    for (int i = 0; i < n; i++)
        p[i] = i * i;                   // 指针可以像数组一样用 [] 下标！
                                        // p[i] 完全等价于 *(p + i)

    // 想扩到 10 个 int：用临时指针接住 realloc 的返回值
    int *tmp = realloc(p, 10 * sizeof(int));
    if (tmp != NULL)                    // 只有成功才更新 p
        p = tmp;
    n = 10;

    for (int i = 5; i < n; i++)         // 前 5 个数据还在，补填后 5 个
        p[i] = i * i;

    free(p);                            // 用完还回去（一对一）
    p = NULL;                           // 防悬空指针
    return 0;
}
```

**新符号清单（第一部分）**：`*`（声明指针/解引用）、`&`（取地址）、`void *`（通用地址类型）、`size_t`（表示大小的非负整数）、`NULL`（空指针）、`sizeof`（求类型占多少字节）、`p[i]` 等价于 `*(p+i)`。

# 第二部分：文件操作

## 一、先认识新面孔：`FILE`、`FILE *`、各种模式字符

### 1. `FILE` —— 标准库定义的"文件结构体"类型

`FILE` 是 `<stdio.h>` 里已经定义好的一个结构体类型（就像你自己定义的 Student），里面装着操作系统管理这个文件需要的全部信息：文件在磁盘哪里、读到第几个字节了、是读模式还是写模式……

你**不需要**关心 FILE 里面是什么，只需要：

```c
FILE *fp;                    // 声明一个"指向 FILE 的指针"
fp = fopen("data.txt", "r"); // 让 fp 指向系统为你建立的那个文件结构体
```

从此所有文件读写函数的第一个参数都是这个 `fp`，意思就是"对 fp 指向的那个文件操作"。

命名习惯：`fp` = file pointer（文件指针），就像 `p` = pointer。

### 2. `fopen` 的第二个参数——模式字符串

```c
fopen("data.txt", "r")   // 第二个参数是"打开方式"，用字符串表示
```

| 模式                       | 字母含义          | 文件不存在时        | 已有内容会怎样    |
| ------------------------ | ------------- | ------------- | ---------- |
| `"r"`                    | **r**ead 只读   | fopen 返回 NULL | 保留         |
| `"w"`                    | **w**rite 只写  | 自动创建          | **全部清空！**  |
| `"a"`                    | **a**ppend 追加 | 自动创建          | 保留，新内容写在末尾 |
| `"r+"`                   | 读 + 写         | 返回 NULL       | 保留         |
| `"w+"`                   | 读 + 写         | 自动创建          | 清空         |
| `"rb"` / `"wb"` / `"ab"` | 二进制的读/写/追加    | 同上            | 同上，但不做换行翻译 |

记忆法：**r 是"读"，w 是"从白纸开始写"（白 = wipe），a 是"接着尾巴写"（append 追加）**。带 `b` 就是按"原样字节"读写，不碰换行符。

### 3. `fopen` 返回值判 NULL

文件打不开（文件不存在、没有权限、路径写错）时，`fopen` 返回 NULL——和 malloc 一个套路。所以标准开头永远是：

```c
FILE *fp = fopen("data.txt", "r");
if (fp == NULL) {
    perror("fopen");   // 打印"fopen: 具体原因"，perror 会自动附上系统给的原因
    return 1;
}
```

**`perror`** 是新函数：print error，把上一次系统调用失败的**人类可读原因**打印出来（比如 "fopen: No such file or directory"）。比 printf 方便，不用自己想原因。

### 4. `fclose` —— 关闭文件

```c
fclose(fp);   // 用完必须关！
```

为什么必须关：

1. 写文件时数据先存在内存缓冲区里，**fclose 才保证它们真正写到磁盘**。不关程序还崩了 → 数据可能丢。
2. 系统同时能打开的文件数量有限，开着不关会耗尽。

## 二、逐个函数拆解（每个 f 开头的函数 = printf 家族的"文件版"）

规律：**原来的函数名前加个 `f`，再在最前面加个 `fp` 参数，就是往文件里操作**。

### 1. `fprintf(fp, 格式, ...)` —— 往文件里"printf"

```c
fprintf(fp, "%s %.1f\n", name, score);
//        ^^^^^^^^^^^^ 和 printf 的格式串一模一样
// ^^^ 只比 printf 多了第一个参数 fp：打印到 fp 指向的文件而不是屏幕
```

`%.1f` 复习：输出小数点后 1 位。

### 2. `fscanf(fp, 格式, ...)` —— 从文件里"scanf"

```c
fscanf(fp, "%31s %lf", name, &score);
//              ^^^^  ^^^
```

两个新写法解释：

- **`%31s`**：`%s` 读字符串，但 `%s` 不限长度是缓冲区溢出隐患。`%31s` 表示**最多读 31 个字符**（留 1 个位置给字符串结尾的 `'\0'`），对应你声明的 `char name[32]`。**数字 = 数组大小减 1**，这是安全写法，考试和工程都该这么写。
- **`%lf`**：读 double 类型。注意和 printf 的区别——printf 输出 double 用 `%f`，scanf 读 double 用 `%lf`（l = long，表示"更宽的浮点"）。scanf 里对 float 才用 `%f`。
- **`&score`**：scanf 家族要的是"地址"，所以变量前要 `&`（name 是数组名本身就是地址，所以不加）。

**fscanf 的返回值**：成功读到了**几个字段**。上面的格式串有 2 个 %，所以正常读到数据返回 2；读到文件尾（没数据了）返回 EOF（EOF 是个常量，值为 -1，意思是 end of file）；读到一半格式对不上返回 1。所以循环这样写最干净：

```c
while (fscanf(fp, "%31s %lf", name, &score) == 2) {
    // 只要成功读到两个字段就继续；读不到 2 个自然退出循环
}
```

### 3. `fgets(数组, 大小, fp)` —— 从文件读"一行"

```c
char line[256];
fgets(line, sizeof(line), fp);
//    ^^^^  ^^^^^^^^^^^^^
//     目标   最多读多少字符（防溢出）
```

三个参数顺序是：**存到哪、最多读多少、从哪读**（注意和 fscanf 不同，fgets 是"目标在前，来源在后"）。

行为：读一行（遇到换行 `'\n'` 停），\*\*把 `'\n' 也一起存进 line**，末尾再加 `'\0'`。读满 `大小-1`个字符也会停。读完文件尾返回 NULL，所以循环条件写`while (fgets(...) != NULL)\`。

**`line[strcspn(line, "\n")] = '\0';` 这行拆解**：

- 它的目的是"去掉行尾那个讨厌的换行符"。
- `strcspn(line, "\n")`：返回 line 里**第一次出现 `'\n'` 的位置**（下标）。不在 `<string.h>` 里，用要 `#include <string.h>`。
- `line[那个位置] = '\0'`：把 `'\n'` 换成字符串结束符 `'\0'`，等于把字符串"从这里截断"，`'\n'` 就没了。
- `'\0'` 复习：字符串结尾标志，值是 0，printf 遇到它就停。

### 4. `fputs` / `fputc` —— 往文件写字符串/字符

```c
fputs("hello\n", fp);   // 把整个字符串写进文件（fputs 不会自动加换行，要自己写 \n）
fputc('A', fp);         // 写一个字符
```

### 5. `fwrite` / `fread` —— 二进制的"整块搬运"

```c
fwrite(stu, sizeof(Student), n, fp);
//     ^^^   ^^^^^^^^^^^^^^^ ^  ^^^
//     从哪块内存开始搬 |   搬几份 | 搬到哪个文件
//              每份多大（字节）
```

读这个函数调用要&#x6309;**"从内存到文件"的方向**理解：把 stu 开始的内存里、每份 sizeof(Student) 字节、一共 n 份，写进 fp。文件会得到 `n × sizeof(Student)` 个"原样字节"，不变成人类能读的文本——用记事本打开是一堆乱码，这是正常的。

```c
fread(&tmp, sizeof(Student), 1, fp);
//     ^^^^                ^
//     读到哪块内存去      读几份
```

方向反过来：从 fp 读 1 份 Student 大小的字节，放进变量 tmp。返回值是**成功读了完整几份**（0 或 1），读到文件尾返回 0，所以 `while (fread(...) == 1)` 能一路读到文件尾。

**`&tmp`**：tmp 是单个结构体变量，fread 要地址，所以加 `&`。

### 6. `feof` —— "刚才是不是碰到文件尾了？"

`feof(fp)` 返回真表示**上一次读取已经试过越过文件尾**。它只适合循环结束后用来区分"正常读完/中途出错"，**不要**写成 `while(!feof(fp))`——那样循环最后一次会用没读到的垃圾数据，多处理一条假记录。记住规则：**循环条件用读函数自己的返回值**。

## 三、把注释标到每一行——综合例子

```c
#include <stdio.h>    // fopen、fclose、fprintf、fscanf、perror 都在这里
#include <stdlib.h>   // malloc、free 在这里（如果用动态数组就需要）

int main(void) {
    /* ---------- 第一步：把三行成绩写进文件 ---------- */
    FILE *fp = fopen("scores.txt", "w");   // "w"：没有就创建，有就清空
    if (fp == NULL) {                      // 打不开 → fp 是 NULL
        perror("fopen");                   // 打印失败原因
        return 1;
    }
    fprintf(fp, "Alice 90\n");             // 往文件写一行（含换行符 \n）
    fprintf(fp, "Bob 75\n");
    fprintf(fp, "Cathy 88\n");
    fclose(fp);                            // 写完必须关，数据才落盘

    /* ---------- 第二步：读回来，求平均 ---------- */
    fp = fopen("scores.txt", "r");         // "r"：只读
    if (fp == NULL) {
        perror("fopen");
        return 1;
    }

    char name[32];      // 存名字的字符数组（数组名本身就是地址）
    double score;       // 存分数
    double sum = 0.0;   // 总分累加器，记得清零
    int cnt = 0;        // 人数计数器

    // fscanf 返回"成功读到几个字段"，格式串里有 2 个 %，读到就 == 2
    while (fscanf(fp, "%31s %lf", name, &score) == 2) {
        sum += score;                      // 累加分数
        cnt++;                             // 人数加一
        printf("%s: %.1f\n", name, score); // 打印到屏幕
    }
    fclose(fp);

    if (cnt > 0)                           // 防止除以 0
        printf("平均分: %.2f\n", sum / cnt);
    return 0;
}
```

运行输出：

```
Alice: 90.0
Bob: 75.0
Cathy: 88.0
平均分: 84.33
```

## 四、二进制 + 动态内存合体例子的逐行注释

这是上一版里最难的例子，逐行拆：

```c
Student *arr = NULL;    // 动态数组还没影，先置 NULL
int n = 0, cap = 0;     // n = 现在装了几个，cap = 内存够装几个
Student tmp;            // 临时变量：每次从文件先读进这里

while (fread(&tmp, sizeof(Student), 1, fp) == 1) {  // 每次读 1 个学生
    if (n == cap) {                     // 数组满了！
        cap = cap ? cap * 2 : 8;        // 三目运算符：cap 为 0 就设 8，否则翻倍
        arr = realloc(arr, cap * sizeof(Student));  // 扩容
        // 简化写法省略了判 NULL，严格写法应像第一部分那样用 tmp 指针接
    }
    arr[n] = tmp;                       // 把刚读到的学生放进数组第 n 个位置
    n++;                                // 数量 +1
}
// 循环结束：fread 返回 0（没东西可读了），n 就是文件里的学生总数
```


```

**`cap = cap ? cap * 2 : 8;` 拆解**（三目运算符 `? :`，你可能还没系统学）：

```c
条件 ? 表达式1 : 表达式2    // 条件为真取表达式1，为假取表达式2
cap ? cap * 2 : 8          // cap 不是 0（已有容量）→ 容量翻倍；cap 是 0（第一次）→ 给 8
```

等价于普通 if-else：

```c
if (cap == 0) cap = 8;
else          cap = cap * 2;
```

这种"容量不够就翻倍扩容"的模式叫**动态数组/可变数组**——C++ 的 `std::vector` 内部干的就是这件事，你现在是手工实现它。

## 五、所有新符号总表（打印贴墙版）

| 符号/关键字 | 读法/含义 | 出现场景 |
|---|---|---|
| `*p` 声明处 | p 是指针 | `int *p`、`FILE *fp` |
| `*p` 语句中 | 顺着地址找变量本身 | `*p = 5` |
| `&x` | 取 x 的地址 | `fscanf(..., &score)` |
| `void *` | 不指定类型的通用地址 | malloc 的返回类型 |
| `NULL` | 空指针（值 0） | malloc/fopen 失败的返回值 |
| `size_t` | 表示大小的非负整数类型 | malloc/calloc 的参数 |
| `sizeof(T)` | T 占多少字节 | `n * sizeof(int)` |
| `FILE` | 标准库的文件结构体类型 | `FILE *fp` |
| `"r"/"w"/"a"` | 读/清空写/追加 | fopen 第二参数 |
| `"rb"/"wb"` | 二进制读/写 | 二进制文件 |
| `EOF` | end of file，值为 -1 | 读函数到达文件尾的信号 |
| `%31s` | 最多读 31 字符的 %s | fscanf 防溢出 |
| `%lf` | scanf 读 double | fscanf |

| `'\n'` | 换行符 | fgets 会把它读进来 |

| `stderr` | 标准错误输出流 | fprintf 的目的地 |
