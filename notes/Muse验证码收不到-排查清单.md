# Muse 验证码收不到 —— 排查清单（微软邮箱）

> 结论先行：**Muse 是 Meta 旗下的服务**，验证码邮件由 Meta 的邮件系统发出，发件域名是
> `facebookmail.com` / `meta.com` / `metamail.com`，发件地址形如 `notification@facebookmail.com`。
> Meta 官方帮助文档里明确写了：**Microsoft Outlook 会把这类邮件判为垃圾邮件**，还会被「聚焦收件箱」的
> 「其他」标签藏起来。所以九成情况下**邮件已经到了，只是没出现在你能看到的地方**。

---

## 第 0 步｜先确认「到底发了没」（最关键，1 分钟）

登录 Meta 账号 → 打开 `facebook.com/recent_emails/security`

- 「账户安全」标签：过去一年的安全邮件
- 「其他邮件」标签：**过去两天**发出的所有邮件

如果你能看到一条 Mimi/Muse 相关的发送记录 → **说明邮件确实发出去了，问题在你的邮箱侧**，继续往下查。
（注意：含验证码的邮件 Meta 会隐藏正文，只显示"已发送"，这是正常的。）

---

## 第 1 步｜去这四个地方找（别只用手机 App 看）

⚠️ **必须用网页版**：浏览器打开 `outlook.com` 登录。手机 App / 桌面客户端都有同步延迟，
有时邮件在服务器上、App 里就是不显示。

| # | 位置 | 怎么进去 |
|---|---|---|
| 1 | **垃圾邮件** | 左侧文件夹列表 → 「垃圾邮件」 |
| 2 | **其他** | 收件箱里的「其他」标签页（聚焦收件箱开着才有）；或直接关掉聚焦收件箱 |
| 3 | **已删除邮件** | 左侧 → 「已删除邮件」（有些过滤规则是直接删） |
| 4 | **存档** | 左侧 → 「存档」 |

**搜索更快**：在搜索框依次搜这些词，每个都要点「搜索所有文件夹」：

```
facebookmail
muse
meta
确认
验证码
confirm
code
```

找到后 → 右键 → **「不是垃圾邮件」**，再把它移到收件箱（这一步等于给过滤器做训练）。

---

## 第 2 步｜加白名单（一劳永逸，防下次丢）

`outlook.com` → 右上角**齿轮 ⚙️** → 邮件 → **垃圾邮件**

1. **安全发件人和域** → 逐个添加这 4 个，每加一个点一次「添加」：

```
facebookmail.com
meta.com
metamail.com
muse.ai
```

2. **阻止的发件人和域** → 检查这里有没有上面任何一个，**有就删掉**
3. 保存

---

## 第 3 步｜检查「静默吃掉邮件」的设置

同样在 ⚙️ 设置里，逐项看：

- **邮件 → 规则**：有没有规则在"移动/删除/转发"Muse 或 Meta 相关的邮件 → 停用或删掉
- **邮件 → 转发**：有没有开着转发到别的邮箱（邮件跑到别人那儿去了）
- **自动清理(Sweep)**：如果以前对某个发件人用过，会持续自动删
- **存储空间**：邮箱满了新邮件会直接被拒 → 设置 → 搜索"存储"检查

---

## 第 4 步｜重发节奏（很多人卡在这）

- 点「重新发送验证码」后，**至少等 60 秒再点第二次**
- **连点 2~3 次会触发限流**，而且**新码会作废旧码**——你以为在"催"，实际每次都把上一封废掉
- 服务端有冷却，通常 10~15 分钟内不要反复请求

---

## 第 5 步｜网络与环境（你这台电脑已经确认没问题）

实测结果：

| 检查项 | 结果 |
|---|---|
| `muse.ai` 域名解析 | ✅ 正常（57.144.64.141） |
| 电脑直连 `muse.ai` | ✅ HTTP 307，1.8 秒 |
| 走代理 | 当前代理未开启，不影响注册页访问 |

但**注册时如果要登录 Facebook / Instagram 账号**，那一步必须能访问 Meta 的服务 →
**建议在手机上注册**（你现在有 Streisand，手机整机走日本线路），比电脑省事。

---

## 第 6 步｜以上都不行，走兜底（最省时间）

按推荐顺序：

1. **换个 Gmail 注册** ← 最推荐。Gmail 对 `facebookmail.com` 的兼容性比 Outlook 好得多，
   而且你已经确认电脑能直连 GitHub、muse.ai，说明国际邮件通路本身没问题
2. **改用手机号验证**（如果 Muse 提供这个选项）
3. 微软邮箱如果是**最近才注册的新账号**，反滥用过滤会格外严，验证码类邮件可能被
   **网关直接丢弃**（连垃圾邮件里都没有）——这种情况在邮箱侧怎么设置都没用，只能换邮箱

---

## 判断口诀

| 现象 | 说明 |
|---|---|
| 垃圾邮件/其他里能找到 | ✅ 纯过滤问题，加白名单后就好 |
| 各文件夹都没有，但 Meta「近期邮件」显示已发送 | ❌ 被微软**网关级丢弃**，设置改不动，**直接换 Gmail** |
| Meta「近期邮件」里也查不到 | ❌ 发送请求没成功 —— 检查邮箱地址是否填错，或注册页在地区限制/等待名单 |
