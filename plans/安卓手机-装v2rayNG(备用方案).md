# 手机装 v2rayNG —— 不用"先有外网"的死循环

> 2026-10-11 · 安装包已下载并校验好，放在 `D:\WorkBuddy\plans\v2rayNG-APK\`

## 先说清楚两个误区

**① Play 商店这条路基本走不通。**
- 实测 `play.google.com` 从你的网络完全连不上（超时）；
- 就算挂上代理能连上，**国行安卓手机出厂就没有 Google Play**（华为连 GMS 都没有）；
- 而且 Play 商店本身也要外网才能用——所以"用 Play 装 v2rayNG 来翻墙"是**死循环**，放弃这条路。

**② GitHub 反而是通的。**
- 实测你的电脑**不开代理**直接访问 `github.com` / `api.github.com` 都返回 200；
- 国内手机浏览器一般也能打开 GitHub，只是 release 里的 27MB 安装包经常下到一半卡死（CDN 慢）。
- 所以：**GitHub 网页可以看，但下载安装包不稳。**

结论：**最稳的办法是"电脑下载好 → 传到手机"**，下面 4 条路任选一条。

## 方式一：USB 数据线（推荐，最简单，100% 能成）

1. 手机用数据线连电脑，手机上把 USB 用途选成「**传输文件 / MTP**」
2. 电脑打开「此电脑」→ 会多出一台手机设备 → 进入 `内部存储\Download\`
3. 把 `v2rayNG_2.2.6_arm64-v8a.apk` 拖进去
4. 手机上：文件管理 → Download → 点那个 apk → 安装
   - 提示「不允许安装未知来源」→ 点「设置」→ 打开「允许来自此来源」→ 返回再装
5. 装完拔线，进方式四的"导入节点"

> 优点：不需要热点、不需要代理、不需要防火墙任何设置。

## 方式二：局域网网页下载（不用数据线，但要开热点）

**前提**：手机能连上电脑的移动热点（走的是局域网，手机不需要外网）。

1. 双击 **`一键启动-手机下载APK.bat`**
   - 会弹 UAC，点「**是**」（需要它放行防火墙的 8000 端口）
   - 窗口里出现"放行成功 / 服务已启动"就对了，**这个窗口别关**
2. 电脑：设置 → 网络和 Internet → **移动热点** → 打开
3. 手机：连上热点 → 打开相机**扫** `手机扫码下载APK.png` 这张图
   （或在手机浏览器输入 `http://192.168.137.1:8000`）
4. 点页面上的「**下载 v2rayNG.apk**」→ 下载完安装（同方式一第 4 步）

**为什么需要管理员**：你的电脑防火墙里有一条**「Python 阻止」**规则（之前某次弹窗点了取消留下的），会拦掉局域网进来的连接——实测 xray 之所以能用，是因为它有一条「允许」规则。这个脚本做的就是给 8000 端口加一条同款「允许」规则，不加的话手机只会一直转圈。

想撤销那条规则：管理员终端跑
`netsh advfirewall firewall delete rule name="v2rayNG APK Server"`

## 方式三：微信 / QQ 传过去（有装客户端的话）

- **微信**：PC 微信 → 「文件传输助手」→ 把 apk 拖进去发送 → 手机微信里点开 → 用其他应用打开 / 保存后安装
- **QQ**：PC QQ → 「我的Android手机」→ 发文件 → 手机 QQ 里下载安装
- 如果微信拒发 `.apk`（个别版本会拦），改用 QQ 或方式一/二

## 方式四：手机自己下载（不想传文件时）

GitHub 国内能打开，走电脑代理更快：

1. 电脑开 v2rayN（选一个能用的节点）+ 开移动热点
2. 手机连热点 → Wi-Fi 详情 → **代理 → 手动**：
   - 主机名 `192.168.137.1`，端口 `10809`
3. 手机浏览器打开：
   `https://github.com/2dust/v2rayNG/releases/download/2.2.6/v2rayNG_2.2.6_arm64-v8a.apk`
4. 下载完安装

> 这个方式走的是电脑的代理端口（10809，防火墙已有放行规则），成功率看 GitHub CDN 当时的心情，卡住就换方式一/二。
