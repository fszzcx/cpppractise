## 第 1 题 · 程序结构

### 题目还原

1. 写程序：用 `//` 写姓名学号；用 `/* */` 写"实验一"。定义 `const double PI=3.141592653589793;`，从键盘读 double r，算周长 `2*PI*r`、面积 `PI*r*r`，用 cout 输出 radius/girth/area 三个值即可。
2. 另写一段：定义局部 `int a;`（不赋值），再定义 `int b=0;`，分别输出 a、b。运行后记录 a 的输出；回答"局部 int 不初始化是否一定为0"。

| **局部变量不初始化的值**      | T0 ★ | P6           | **能说出为什么**（你已做过 lab1_uninit） |

### 必须能回答的问题

**"局部 int 不初始化是否一定为 0？"** —— 不一定。局部变量存于栈上，不初始化时它的值是**这块内存上一次留下的垃圾值**，每次运行可能都不同。C 和 C++ 都不保证它为 0（全局变量/静态变量才会被零初始化）。

## 第 3 题 · const 用法 ★核心

### 题目还原

1. 用 `const double PI=...` 和 `const int MAXN=1000;` 算圆面积；尝试在后面写 `PI=3.14;`、`MAXN=2000;`，把编译报错截下来，说明 const 对象为什么不能改。
2. 定义并观察以下四类，逐行判断哪行合法、哪行报错：
   - `const int x=1;` 后尝试 `x=2;`
   - `const int A=78; int c=13; const int* p=&A;` 后尝试 `*p=1;`、`p=&c;`
   - `int v=5; int* const q=&v;` 后尝试 `q=&c;`、`*q=9;`
   - `const int M=10; const int* const r=&M;` 后尝试 `r=&v;`、`*r=1;`
3. 写"指向常量的指针"指向普通变量：说明通过它为什么也不能写。

### 知识点清单

| 知识点                               | 层级   | 鹏哥集数     | 掌握标准                  |
| --------------------------------- | ---- | -------- | --------------------- |
| const 对象初始化后不可赋值                  | T0   | P7       | 能说出编译器为什么拦截           |
| **const 在 `*` 左边**：`const int* p` | T0 ★ | P105–110 | 指向的**值**不能改，**指向**可以改 |
| **const 在 `*` 右边**：`int* const q` | T0 ★ | P105–110 | **指向**不能改，**值**可以改    |
| **两边都有**：`const int* const r`     | T0 ★ | P105–110 | 都不能改                  |
| 指向常量的指针 → 普通变量                    | T0   | P105     | 通过该指针不能写，但变量自己可以改     |

### 必须背下的判断口诀

> **看 const 在 `*` 的哪一边：在左边 → 不能改 `*p`；在右边 → 不能改 `p`。**

### 必须能回答的问题

- 四种组合各自哪行合法、哪行报错（要能逐行说理由，不是背答案）。
- "指向常量的指针指向普通变量，为什么也不能写？" —— 因为**通过这个指针**写入是被编译器禁止的；但绕过它直接改变量是允许的。这是编译期的规则，不是运行期的保护。

## 第 4 题 · 指针用法 ★核心

### 题目还原

1. 定义 `int x=10; int* p=&x;`，输出 x、`*p`、`&x`、p；再用 `*p=100;` 改值并输出 x。
2. 写两段对比运行：
   - 定义 `int* q;` 不初始化直接 `cout<<*q;`（观察危险/报错）
   - 定义 `int* q=nullptr;` 判断 `if(q==nullptr)` 再解释引用，否则输出 "null pointer"。
3. 写两个版本：
   - 用指针**交换所指对象的值**：主函数 11,12，调用后 11,12 互换。
   - **只交换两个指针变量本身**：主函数 `p1=&i1, p2=&i2`，交换 p1,p2 后输出 `*p1,*p2,i1,i2`，说明 i1,i2 是否变化。
4. 判断并改错：`int i=0; double* dp=&i;`、`int* ip=i;`、`void* vp=&i;` 后直接 `*vp` 使用。说明类型匹配和 `void*` 强转。

### 知识点清单

| 知识点                      | 层级    | 鹏哥集数       | 掌握标准               |
| ------------------------ | ----- | ---------- | ------------------ |
| 指针定义 / `&` 取地址 / `*` 解引用 | T0 ★★ | P77        | 能画内存图              |
| **野指针**（未初始化就解引用）        | T0 ★★ | P79        | 知道这是未定义行为          |
| `nullptr` 空指针检查          | T0    | C++ 内容     | 知道 C 里是 NULL       |
| **交换值 vs 交换指针**          | T0 ★★ | P77–82     | 能说清 i1,i2 何时变、何时不变 |
| 类型匹配：`double*` 不能指 int   | T0    | P77        | 知道编译器会报错           |
| `void*` 万能指针必须强转后才能解引用   | T0    | P82 / P110 | 能写出 `*(int*)vp`    |

### 必须能回答的问题

- **"交换 p1,p2 后，i1、i2 变了吗？"** —— 没变。交换的是两个指针变量里存的**地址**，i1、i2 那两块内存纹丝不动；只是 p1、p2 现在"指向的对象"对调了。
- **"为什么 `*vp` 不能直接用？"** —— `void*` 只知道"这里有个地址"，不知道"那是什么类型"，编译器无法确定该读几个字节，必须先强转回具体类型。

## 第 5 题 · 引用用法 ★★纯 C++，C 课没有！

### 题目还原

1. 定义 `int x=5; int& r=x;`，通过 `r=10;` 改值，输出 x、r、\&x、\&r。
2. 尝试写：`int& r2;`、`int& r3=10;`、`double d=3.14; int& r4=d;` 记录每句为什么错。
3. 写：
   ```cpp
   int x=1, y=2;
   int& r=x;  r=y;
   ```
   输出 x、y、r，回答"是否变成 y 的引用"。
4. 写函数 `void swap(int& a, int& b);` 交换主函数两个整数；再写 `const int& ra=a;`，尝试 `ra=1;`、尝试 `const int& rb=a*2;`、`const int& rc=42;`，说明引用能用做什么、不能做什么。

### 知识点清单

| 知识点                      | 层级    | 鹏哥集数   | 掌握标准                   |
| ------------------------ | ----- | ------ | ---------------------- |
| **引用是别名，必须初始化**          | T0 ★  | C++ 内容 | 知道 `int& r2;` 为什么错     |
| 普通引用不能绑字面量 `int& r3=10;` | T0 ★  | C++ 内容 | 知道为什么                  |
| 引用类型必须一致 `int& r4=d;`    | T0 ★  | C++ 内容 | 知道为什么                  |
| **引用不能改绑**：`r=y` 是赋值不是改绑 | T0 ★★ | C++ 内容 | **本题最易错点**             |
| 引用作函数参数实现 swap           | T0 ★  | C++ 内容 | 这就是引用被发明的原因            |
| const 引用：能绑字面量/临时值       | T0    | C++ 内容 | `const int& rc=42;` 合法 |

### 必须能回答的问题

- **"r=y 之后，r 是不是变成 y 的引用了？"** —— **不是**。引用一旦绑定就**终生绑定**，`r=y` 只是把 y 的**值**赋给 r（也就是赋给 x），所以 x 变成 2，r 依然指向 x。
- **"\&x 和 \&r 的输出？"** —— 完全相同，因为 r 就是 x 的别名，是同一块内存。
- **"为什么 `const int& rc=42;` 合法而 `int& r3=10;` 非法？"** —— 绑字面量会生成临时对象，普通引用意味着"我可能要改它"，但改一个临时对象毫无意义且危险，所以只允许 const 引用。

## 第 6 题 · 程序改错（三段代码，逐行判断）

### 6-A 还原

```cpp
#include <iostream>
using namespace std;
int main() {
    int a;                       // ①
    int b = 5;
    const int n;                 // ②  错：const 必须初始化
    const double PI = 3.14159;
    a = b + 10;
    cout << a << endl;
    cout << b << endl;
    n = 20;                      // ③  错：const 不能赋值
    PI = 3.14;                   // ④  错：const 不能赋值
    int x = 5, y = 2;
    cout << x / y << endl;       // ⑤  观察：整数除结果是否符合预期
    cout << double(x) / y << endl;
    char c;
    cin >> c;
    cout << int(c) << endl;
    cout << int(c + 1) << endl;  // ⑥  观察：char参与算术会转int
    return 0;
}
```

### 6-B 还原

```cpp
#include <iostream>
using namespace std;
int main() {
    int* p;                      // ①  错：野指针
    int v = 10;
    cout << *p << endl;          // ②  错：解引用野指针
    int* q = nullptr;            // ③
    cout << *q << endl;          // ④  错：解引用空指针
    const int k = 100;
    int* pk = &k;                // ⑤  错：int* 不能指向 const int
    *pk = 200;                   // ⑥  错：试图改常量
    int m = 1;
    const int* cp = &m;          // ⑦
    *cp = 50;                    // ⑧  错：const int* 不能改值
    cp = &v;                     // ⑨  合法：指向可以改
    int* const qc;               // ⑩  错：指针常量必须初始化
    qc = &v;                     // ⑪  错：指向不能改
    *qc = 99;                    // ⑫  合法（若⑩已初始化）：值可以改
    double d = 1.2;
    int* pd = &d;                // ⑬  错：类型不匹配
    void* vp = &v;
    cout << *vp << endl;         // ⑭  错：void* 不能直接解引用
    return 0;
}
```

### 6-C 还原

```cpp
#include <iostream>
using namespace std;
int main() {
    int& r1;                     // ①  错：引用必须初始化
    int x = 5;
    int& r2 = x;
    cout << r2 << endl;
    int& r3 = 10;                // ②  错：普通引用不能绑字面量
    double d = 3.14;
    int& r4 = d;                 // ③  错：类型不匹配
    int a = 1, b = 2;
    int& r5 = a;
    r5 = b;                      // ④  观察：r5还绑a还是改绑b? a、b各变多少
    cout << a << b << r5 << endl;
    const int c = 7;
    int& r6 = c;                 // ⑤  错：普通引用不能绑 const 对象
    const int& r7 = c;
    r7 = 8;                      // ⑥  错：const 引用不能改
    const int& r8 = a * 2;       // ⑦  合法：const 引用可以绑临时值
    const int& r9 = 42;          // ⑧  合法：const 引用可以绑字面量
    return 0;
}
```

### 知识点清单

这一题是**前 5 题的综合体检**，没有任何新知识点。

- 6-A 考：const 必须初始化、const 不能赋值、整数除、char 转 int
- 6-B 考：野指针、空指针、const 指针三种组合、类型匹配、void*
- 6-C 考：引用三规则（必须初始化/不能绑字面量/类型一致）+ 不可改绑 + const 引用

### 必须能回答的问题

- **6-B ⑨ `cp = &v;` 合法吗？** —— 合法。`cp` 是 `const int*`，约束的是"不能通过它改值"，**没约束指向**。
- **6-C ④ `r5 = b;` 之后 a、b 各是多少？** —— a=2, b=2。r5 依然绑定 a，`r5=b` 是把 b 的值赋给 a（**不是改绑**）。
- **6-C ⑦⑧ 为什么合法？** —— 因为是 `const int&`。绑临时值/字面量时编译器生成一个临时对象，而 const 引用承诺不修改它，所以放行。

## 第 7 题 · 综合题

### 题目还原

1. 定义两个 int 变量并初始化 `int a = 12, b = 7;`，分别用**指针**和**引用**对它们进行交换。
2. 定义两个 char 变量 `char lower='x'; char upper='M';`，分别把它们转成大写和小写。

### 知识点清单

| 知识点                      | 层级    | 掌握标准    |
| ------------------------ | ----- | ------- |
| 指针版 swap（传地址）            | T0 ★★ | 不查资料写出来 |
| 引用版 swap（传引用）            | T0 ★★ | 不查资料写出来 |
| char 大小写转换 `-32` / `+32` | T0    | 不用库函数   |

### 必须能回答的问题

**"两个 swap 函数体几乎一样，区别只在参数，为什么都能行？"** —— 指针版传的是**地址**（副本），但通过 `*a` 操作的是原对象；引用版传的是**别名**，直接操作原对象。**两者的共同本质是：都拿到了"原对象的入口"。** 这正是第 4/5 题想让你体会的东西。
