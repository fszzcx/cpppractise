# C 语言课学习深度清单（主攻 C++ 版）

> 适用：目标是主攻 C++，C 语言只是过渡与打底。  
> 结论先行：**C 课只需精学「前 60%~70%」，其中 T0 那一层占你 90% 的精力。**

---

## 一、唯一需要记住的判断准则

C 课里的内容，只有两类。判断标准只有一句话：

> **这是 C++ 也照搬的底层机制，还是 C 时代没有语言支持时的"土办法"？**

| 类型           | 处理方式             | 例子                     |
| ------------ | ---------------- | ---------------------- |
| C++ 也照搬的底层机制 | **学透**（T0）       | 指针、内存布局、数组退化、编译链接、结构体  |
| 没有语言支持时的土办法  | **跳过或略读**（T2/T3） | 用宏模拟泛型、用函数指针表模拟类、手写内存池 |

再补一句更狠的：

> **C 课的目的不是让你会写 C 程序，而是让你搞懂「程序在内存里到底怎么跑」。**

C++ 后来所有"高级"机制（引用、析构函数、RAII、智能指针、移动语义）**都是在填 C 时代手动管内存的坑**。你没有经历过那段痛，学 C++ 就只能背语法，永远不知道那些东西为什么存在。

## 三、T0 精通级：必须徒手写出来

> 这一层的知识 **100% 被 C++ 继承**，没有一项可以省。

### 1. 基本类型与类型转换

- **掌握程度**：各类型的位数与取值范围；有符号/无符号混用陷阱；整数溢出与截断；浮点精度问题（`0.1 + 0.2 != 0.3`）；隐式转换规则
- **为什么 C++ 需要**：这些坑在 C++ 里一个不少，而且 C++ 类型更多（`bool`、引用、类类型转换），坑位只增不减

### 2. 运算符与位运算

- **掌握程度**：优先级与结合性；短路求值；`& | ^ ~ << >>`；用掩码做置位/清位/取值
- **为什么 C++ 需要**：位运算完全通用；`std::bitset`、枚举标志位、哈希实现都依赖它

### 3. 流程控制

- **掌握程度**：`if/else`；`switch`（含 `break` 穿透陷阱）；`for/while/do-while`；`break/continue`；`goto` 知道但别用
- **为什么 C++ 需要**：完全通用，另外 C++ 多了范围 `for`，但那是在这之上的语法糖

### 4. 函数

- **掌握程度**：声明与定义分离；**值传递的本质是复制一份**；返回值的传递机制；递归；作用域与生命周期；栈帧概念
- **为什么 C++ 需要**：C++ 在此之上加了引用传参、重载、默认参数、`inline`——**但前提是你知道值传递到底复制了什么**
- **重点理解**：为什么 C 非要传指针才能改外部变量？**这正是 C++ 引用被发明出来的动机。** 想通这一点，引用就不需要背了

### 5. 数组与 C 风格字符串

- **掌握程度**：数组内存连续；数组名退化为指针；越界不报错（这是特性不是 bug）；`char` 数组与 `'\0'`；`sizeof(arr)` 与 `sizeof(ptr)` 的区别
- **为什么 C++ 需要**：`std::vector` / `std::string` / `std::array` 本质就是在替你做这件事——不学 C 数组，你体会不到它们好在哪

### 6. 指针 ★★★ 重中之重

- **掌握程度**：`&` 取地址与 `*` 解引用；指针类型为什么有类型；指针运算；指针与数组的关系；多级指针；指针作参数与返回值；函数指针（基础）；`NULL` 与野指针
- **为什么 C++ 需要**：C++ 的引用、`this` 指针、虚函数表、迭代器、智能指针，**本质都是"指针换个马甲"**
- **警告**：**指针不牢，C++ 一生受困。** 这一块值得花掉你 C 课总时间的三分之一

### 7. 结构体 / 联合 / 枚举 / typedef

- **掌握程度**：定义与初始化；**内存布局与对齐**；结构体指针与 `->`；结构体嵌套；`typedef` 简化
- **为什么 C++ 需要**：C++ 的 `class` 就是"能带成员函数、带访问控制的 struct"。`struct` 的内存布局知识在 C++ 里同样直接适用

### 8. 动态内存 ★★ 重点

- **掌握程度**：`malloc / calloc / realloc / free`；按字节分配与 `sizeof` 的配合；内存泄漏、悬空指针、重复释放、越界写这四类 bug 的成因
- **为什么 C++ 需要**：`new / delete`、构造与析构、RAII、智能指针，全是在修这一层的坑。**没被 malloc/free 坑过的人，理解不了 unique_ptr 的意义**

### 9. 预处理与多文件工程

- **掌握程度**：`#include` 两种形式（`<>` 与 `""`）的区别；**头文件卫士**（`#ifndef` / `#pragma once`）；`#define` 常量与带参宏的基本用法；条件编译 `#ifdef`
- **为什么 C++ 需要**：头文件机制完全相同；"声明放 `.h`、定义放 `.c/.cpp`"是大型项目的组织基础，C++ 也照用

### 10. 编译与链接

- **掌握程度**：预处理 → 编译 → 汇编 → 链接 四步各自做什么；**声明 vs 定义**；为什么需要链接；静态库与动态库的概念
- **为什么 C++ 需要**：`extern "C"`、为什么模板不能分离编译、头文件包含顺序、重复定义错误……**这些问题的答案全在这一层**

### ✅ T0 验收标准

用**纯 C**（不许使用任何 C++ 特性）独立完成一个「学生成绩管理」小项目：

- [ ] 结构体数组，或结构体指针 + `malloc` 动态分配
- [ ] 增、删、改、查 + 按成绩排序
- [ ] 至少 3 个文件：`main.c` / `student.c` / `student.h`
- [ ] 数据能存入文件、也能读回来
- [ ] 不查教程、编译器零错误、内存检查（valgrind 或 VS 内存工具）无告警

**做到这些 → T0 毕业，可以全力转 C++ 了。**

## 五、T2 了解级：扫一眼，知道有这回事就行

- VLA 变长数组（C99）—— **C++ 不支持，写 C++ 时别用**
- `restrict`、`_Noreturn`、`_Alignas` 等 C99/C11 关键字
- `_Generic`、`_Static_assert`、`_Atomic`
- `setjmp / longjmp`（C 的"异常"，C++ 用真正的异常机制替代）
- 宏的高级技巧：`#`、`##`、变参宏
- 柔性数组成员（flexible array member）

## 六、T3 跳过级：对 C++ 人无价值，甚至有害

| 内容                                   | 为什么跳过                                                 |
| ------------------------------------ | ----------------------------------------------------- |
| K\&R 风格函数定义 `int f(a,b) int a,b; {}` | 早已废弃，看懂就行                                             |
| 用宏模拟泛型                               | C++ 有模板，宏只会带来灾难                                       |
| 手写内存池 / 手写链表、哈希表                     | 先把 **STL 容器**学会，别急着造轮子（C 课最爱留这种作业，做一遍懂原理就够，**别养成习惯**） |
| 用函数指针结构体表模拟"面向对象"                    | 那是没有 `class` 时的权宜之计                                   |
| `gets()`、无长度限制的 `strcpy` 等危险函数       | 危险且已废弃                                                |
| C 式手工字符串拼接与内存管理习惯                    | C++ 里一律用 `std::string`，别把坏习惯带过去                       |

## 七、时间怎么分配

- **总时长**：C 课的前 **60%~70%** 就是全部你需要的内容，剩下的进度可以放松听
- **精力分配**：T0 占 90%，其中「**指针 + 内存 + 结构体**」三块约占总时间的一半
- **学习方法**：每学完一个 T0 知识点，**立刻在 VSCode（g++）里用 `.cpp` 重写一遍并对比**——这是 C→C++ 最有效的过渡方式

---

## 八、转 C++ 时立刻要建立的 5 个新习惯

1. 分配内存就写 `new / delete`（先别急着上智能指针），写下就立刻配对
2. 字符串一律 `std::string`，只在对接 C 接口时才用 `.c_str()`
3. 常量一律 `const` / `constexpr`，不再用 `#define`
4. 要"改外部变量"优先用引用 `&`，而不是传指针
5. 需要数组 / 链表 / 哈希表，先想 STL 容器（`vector` / `list` / `unordered_map`），而不是自己造
