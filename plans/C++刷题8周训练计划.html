C++ 刷题 8 周训练计划

从只会基础语法，到能独立解算法题
0 / 0

开始之前，先记住五条方法

  1. 20 分钟规则 —— 一道题自己啃 20 分钟毫无进展，就去看题解。但看完必须关掉题解，从头自己重写一遍。抄一遍不等于会，重写才是。
  2. 建错题本 —— 每道卡住的题记三行：题目链接 / 卡在哪 / 关键思路。每周日花 30 分钟重做一遍。这是整个计划里复利最高的一件事。
  3. 按主题刷，不要随机刷 —— 一周只专注一个知识点。跳着刷会感觉每题都是新的，进步极慢。
  4. 提交前先自己造数据 —— 测最小值、最大值、空数据、全相同。这个习惯在面试现场能救你。
  5. 看题解要看"为什么" —— 不只看代码，看作者是怎么想到的。思考过程比代码值钱。

每周节奏（对应 10–20 小时投入）

  • 周一、周二：学新知识点，各 2 小时
  • 周三到周五：每天 1–2 题，各 1.5 小时
  • 周六：专攻本周最难的一题，2–3 小时
  • 周日：重做本周错题 + 总结，1–2 小时

STL 速查表（刷题只用到这些）

// 万能头文件，刷题时用它就不用记一堆 include
#include <bits/stdc++.h>
using namespace std;

// 加速输入输出 —— 刷题必写这两句，否则大数据量会超时
ios::sync_with_stdio(false);
cin.tie(0);

// vector：变长数组，最常用
vector<int> v;
v.push_back(1);
v.size();
sort(v.begin(), v.end());

// pair：打包两个值，常配合 vector 用
pair<int,int> p = {1, 2};
p.first;  p.second;

// map：键值对，统计词频神器
map<string,int> cnt;
cnt["apple"]++;
for (auto &kv : cnt) cout << kv.first << kv.second;

// unordered_map：更快，但无序
unordered_map<int,int> mp;

// set：自动去重 + 有序
set<int> s;
s.insert(3);
s.count(3);   // 返回 1 表示存在，0 表示不存在

// stack / queue
stack<int> st;  st.push(1); st.top(); st.pop();
queue<int> q;   q.push(1); q.front(); q.pop();

// priority_queue：默认大根堆
priority_queue<int> pq;
priority_queue<int, vector<int>, greater<int>> minHeap;  // 小根堆

// 二分：第一个大于等于 x 的位置
int idx = lower_bound(a, a + n, x) - a;

八个必踩的坑（提前避开能省几十小时）

  • int 溢出 —— 数字大就换 long long，乘法前先转类型。int 上限约 21 亿，求和很容易超过。
  • 数组开小 —— 题目说 n ≤ 1000，你开 a[1005] 或 a[1010]，不要刚好开 1000。
  • cin/cout 慢 —— 忘写那两句加速，大数据量直接超时。或者改用 scanf/printf。
  • 局部变量未初始化 —— 全局变量默认是 0，局部变量是随机值。累加器记得手动置 0。
  • getline 前有残留换行 —— 前面用过 cin >> 的话，先加一句 cin.ignore()。
  • 浮点数别用 == 比较 —— 用 fabs(a-b) < 1e-6。
  • 死循环 —— 检查 while 条件里的变量到底有没有变化。
  • 求最小值时初始值设小了 —— 要设成一个"足够大"的数，否则永远输出初始值。

8 周结束后，你应该能做到

  • 独立用 C++ 实现：排序、二分查找、DFS / BFS、01 背包
  • 30 分钟内独立解出一道洛谷「普及-」难度的题
  • 累计刷题量 60 道以上，有完整的错题本
  • 这些能力直接对应：蓝桥杯省赛、大厂笔试、面试手撕代码环节
如果中途卡住超过两周没有进展，先回头看第 5 周的递归和第 6 周的 STL——90% 的卡壳都出在这两处。
