# iPhone 用上境外网络 —— 完整方案

> 2026-10-11 · 适用于你手上这台 iPhone

## 一、为什么之前那套全废了

系统识别到你的手机是 **iPhone**（USB 设备 ID `USB\VID_05AC&PID_12A8`，`VID_05AC` 是苹果的厂商编号）。

iOS 有两条硬限制，跟安卓完全不同：

| | 安卓 | iPhone |
|---|---|---|
| 能不能装 APK | 能 | **不能**，iOS 只装 App Store 的应用（.ipa） |
| USB 拷文件 | 随便拷 | **只能传照片/视频**，而且要装 Apple 驱动；拷 apk 必然报错 |
| Wi-Fi 系统代理 | 支持 HTTP | 支持 HTTP（**不支持 SOCKS**） |

所以你遇到的「无法移到手机」，不是线坏了、也不是驱动问题——**iOS 本来就不接受这种文件**。前面给你的 APK 那套方案是我没先确认机型，白折腾了，抱歉。

## 二、路线一：零安装，5 分钟能用（先做这个）

**不需要在手机上装任何东西**，用 iOS 自带的 Wi-Fi 代理。

### 前提：电脑上 v2rayN 必须先跑起来并选好节点

1. 双击 `C:\Users\fszzc\Desktop\VPN\v2rayN\v2rayN.exe`
2. 在节点列表里点一个日本节点（推荐 **`日本Y01 | IEPL`** 这类 `.qpon` 的 SS 节点，广告图已验证域名仍在解析）
3. 底部状态栏出现延迟数字 = 连上了

### 然后：开热点，手机设代理

4. 电脑：设置 → 网络和 Internet → **移动热点** → 打开
5. iPhone：连上这个热点
6. iPhone：**设置 → 无线局域网 → 点热点名右边的 ⓘ → 滑到最底 → 配置代理 → 手动**
   - 服务器：`192.168.137.1`
   - 端口：**`10809`**
   - 「鉴定」开关**不要**打开
   - 右上角「**存储**」
7. 验证：Safari 打开 `https://api.ip.sb/geoip`，国家显示 Japan / Hong Kong 就通了

### 三个必须知道的坑

- **端口一定是 10809，不能是 10808**。10808 是 SOCKS 协议，**iOS 的系统代理只认 HTTP**，填 10808 会直接断网。
- **iOS 的代理是按 Wi-Fi 网络分开存的**：你只在这个热点上设了代理，换到别的 Wi-Fi 就没了；反过来，如果以后在「设置」里点「忽略此网络」，代理设置会一起被删掉。
- **只覆盖 Wi-Fi，蜂窝数据（4G/5G）不走**；而且微信、抖音、淘宝这类自带网络栈的 App 照样可能直连。Safari、YouTube、GitHub、App Store 这些没问题。

### 变体：不想开热点？

如果你的 iPhone 也连着校园网 `GZHU-student`，把代理服务器换成电脑在校园网的地址：

```
服务器：172.26.206.250
端口：  10809
```

省掉开热点这一步。**但**：学校 Wi-Fi 常开「AP 隔离」（同一网络内设备互相不通），那就连不上，还是得用热点。

> 电脑的校园网 IP 是 DHCP 分配的，重启/重连后可能变。用之前先在电脑上 `ipconfig` 看一眼 WLAN 那行的 IPv4 地址。

## 三、路线二：装 iOS 客户端（长期、彻底，但需要折腾一次）

想要**全机走境外**（含 4G/5G、含微信抖音这些不理系统代理的 App），必须装一个会创建 VPN 描述文件的客户端。而这类工具**国区 App Store 没有**，得用**非中国区 Apple ID**。

### 第 1 步：弄一个美区 Apple ID

- **建议新注册一个号**，而不是改现有账号的地区——改地区要先取消账号里所有订阅，风险大。
- 邮箱用 Gmail / Outlook 之类的；
- 地区选 **United States**；
- **付款方式选「无」(None)**；
- 地址随便填一个美国地址，但要能过校验。可参考：
  ```
  City:  San Francisco
  State: California
  Zip:   94101
  电话:  001650-3556
  ```
- **只用它登录 App Store，不要登 iCloud**。两个账号各管一摊：国区 ID 管 iCloud（照片、通讯录、备份），美区 ID 只管下载 App，互不干扰。

### 第 2 步：装客户端

在美区 App Store 搜下面这些名字，**哪个搜得到就用哪个**：

| 名称 | 费用 | 说明 |
|---|---|---|
| **Shadowrocket**（小火箭） | 约 $2.99 | 最通用，SS / VMess / VLESS / Trojan 全支持；付费需要美区 App Store 礼品卡充值 |
| **sing-box** | 免费 | 官方出品，功能最全，界面偏技术向 |
| **Streisand** | 免费 | 免费里比较友好的一个 |
| **V2Box** / **Karing** | 免费 | 备选 |

> 优点：装上之后**不依赖电脑、不依赖热点**，4G/5G 下也全局生效。

### 第 3 步：导入节点

- 方式 A：把 `节点ss链接(安卓iOS通用).txt` 的内容**复制** → 客户端里找「从剪贴板导入」
- 方式 B：打开 `节点二维码(安卓iOS通用).png` 显示在电脑屏幕上 → 客户端里点「扫二维码」
  （注意：**必须用客户端自带的扫码功能**，用 iPhone 相机扫 ss:// 只会显示一串文本）

### 第 4 步：验证

连接后 Safari 打开 `https://api.ip.sb/geoip`，看国家是不是 Japan。

## 四、两条路线怎么选

| | 路线一 · 系统代理 | 路线二 · iOS 客户端 |
|---|---|---|
| 要在手机装东西 | **不用** | 要（美区 App Store） |
| 覆盖范围 | 只有 Wi-Fi + 遵守系统代理的 App | **全机**（含蜂窝）+ 几乎所有 App |
| 需要电脑开着 | **是** | 否 |
| 上手难度 | ★☆☆☆☆ | ★★★☆☆（卡在美区账号） |
| 适合 | 临时用、看网页/YouTube | 长期用、什么 App 都要走 |

**建议**：先按路线一把当前需求解决掉（电脑开 v2rayN → 手机设代理，两分钟），确认整条链路是通的；等哪天想彻底摆脱电脑，再花半小时折腾路线二。

## 六、实测记录（2026-10-11 晚，已跑通 ✅）

**最终走通的方案：路线二 · iPhone 装 Streisand 客户端直连节点**，不走电脑、不开热点。

| 环节 | 结果 |
|---|---|
| 客户端 | **Streisand**（iPhone，主页 → 右上「+」→ 导入 → 电源键连接） |
| 导入方式 | **扫二维码成功** ✅ |
| 导入方式 | 从剪贴板导入 **失败** ❌ —— iOS 的粘贴权限拦截，见下方规避 |
| 节点 | 日本Y01 \| IEPL（`.qpon` 域名，实测出口为日本东京） |
| 首次连接 | 弹「要添加 VPN 配置吗」→ 允许 + 锁屏密码，必须点 |

**关键经验**：

1. **iOS 上「从剪贴板导入」经常不生效**，别在上面浪费时间——直接用**扫码**，`节点二维码(安卓iOS通用).png` 里 4 个节点扫码即导入。
2. 用 iPhone **相机**扫 `ss://` 二维码只会显示一串文本，**必须用客户端自带的扫码**（Streisand 里「+」→ 扫描二维码）。
3. 连上后**记得把 Wi-Fi 的系统代理改回「无」**（设置 → 无线局域网 → ⓘ → 配置代理 → 关闭），否则两套代理会互相干扰。
4. 走通之后**电脑和热点都可以关了**，这台 iPhone 是直连节点，不再依赖 `192.168.137.1`。
